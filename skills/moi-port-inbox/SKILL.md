# Moi Port inbox

Use the Moi Port MCP tools when authenticated.

1. Confirm which workspace/tenant the user means.
2. Prefer read-only tools first (list conversations, get thread, lead summary).
3. Never send a customer-facing message without an explicit yes.
4. If MCP is unavailable, say so and fall back to guiding them in the Moi Port web UI (moiport.com).
